# Counter, Stopwatch, and Clock Builder  

This project helped me practice OOP concepts through a practical application. It was built using **Vanilla JavaScript** and styled with **Sass**, applying encapsulation, abstraction, polymorphism, and inheritance.  

## Features  

- **Counter**: Increments or decrements values.  
- **Stopwatch**: Tracks time with start, stop, and reset functions.  
- **Clock**: Displays the current time, updating every second.
